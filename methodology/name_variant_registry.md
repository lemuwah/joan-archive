# Name Variant Registry — Master Search Key

**Purpose:** Every name connected to Joan's world, with all plausible variants.
Used as the search key for every repository, every record type, every search.

**Variant Types:**
- **Standard:** Known spellings from primary/secondary sources
- **Scribe drift:** Period handwriting variations (e/a swap, doubled letters, abbreviations)
- **OCR-plausible:** Common OCR misreads of period script (u/n, e/c, rn/m, cl/d, li/h)
- **Phonetic:** Sound-alike spellings that a clerk hearing a name might produce

**Rule:** Search ALL variants for each name in every repository. Log which variants were searched in NEGATIVE_LOG.md.
