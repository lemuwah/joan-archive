## Resolution Rules

1. A contradiction moves to 🟡 LEANING RESOLVED only when a primary source or AI transcription of a primary source supports one side AND no primary source contradicts it.
2. A contradiction moves to 🟢 RESOLVED only when a primary source has been directly read by archive staff (not AI, not secondary abstracts).
3. A contradiction moves to 🔴 CLOSED when a primary source definitively eliminates one side.
4. **Every status change must be documented:** which source, which date, who changed it, what it said. See `methodology/editorial_standards.md` §3.
