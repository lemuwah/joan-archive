# Network Map — Who Connects to Whom

**Purpose:** Map every documented connection between people in Joan's world.
When enough data accumulates, this becomes the visual constellation.

## Connection Types
- **DEED** — named in the same deed (grantor, grantee, witness, bounds neighbor)
- **PROBATE** — named in the same estate record
- **COURT** — named in the same court case
- **CHURCH** — named in the same congregation record
- **FAMILY** — documented family relationship
- **NEIGHBOR** — adjacent property or same community
- **INVENTORY** — mentioned in another person's estate inventory
