# Geographic Index — Every Place in Joan's World, Every Way It Was Written

**Status:** ACTIVE reference — feeds the Greene Net ([methodology/collection_policy.md](../methodology/collection_policy.md))
**Date:** 2026-09-09
**Machine-readable twin:** [data/geography.yml](../data/geography.yml)

**How to use:** When a record names a place, file the lead under every region it touches using this index. When searching a repository, search **every variant** of the region, not just the modern spelling. Colonial clerks spelled by ear and habit; the same place appears under a dozen forms across jurisdictions. A variant is only "attested" when a record — ours or a cited one — actually used it. Everything else is a search target, never a citation.

**Attribution status key**
- ✅ **anchored-in-repo** — the spelling appears in a document inside this archive
- 📖 **external-reference** — standard in period literature, not yet anchored here; verify before citing
- 🎯 **search-target** — plausible scribe-drift or OCR form; search and log it, never cite it

## The scribe-attribution program (standing)

The user-facing question — *"who was writing it down?"* — is a research program, not a guess:

1. When a record's clerk/scribe/notary is known, attach the name to the variant row here and in the yml.
2. When unknown, the variant stays `unattributed` — and "identify the scribe of this record" becomes a queue item.
3. The Fones Record, the Kingstowne land evidences, and the Warwick town books each had keepers whose names we do not yet control. Finding them is Task 6.75-adjacent and feeds [scribes_of_the_great_migration.md](scribes_of_the_great_migration.md).

*Bias check: this index is built from English colonial records. Narragansett and Niantic place knowledge belongs to those communities; community-governed sources are listed in the scribes/companion document and approached under D-005 tags and the universal disclaimer.*
